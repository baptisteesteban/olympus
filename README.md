# Olympus, a Generic Image Processing Library

[![License: MPL 2.0](https://img.shields.io/badge/License-MPL_2.0-brightgreen.svg)](https://opensource.org/licenses/MPL-2.0)
[![Build and Test](https://github.com/baptisteesteban/olympus/actions/workflows/build_and_test.yml/badge.svg)](https://github.com/baptisteesteban/olympus/actions/workflows/build_and_test.yml)

Olympus aims to be a generic image processing library implemented in Rust. It is
strongly inspired by the [Olena](https://gitlab.lre.epita.fr/olena/olena)
platform and the [Pylene](https://gitlab.lre.epita.fr/olena/pylene) library in
C++. It aims to be my personal library for my research but may be used in other
situations. It has been created due to two facts: first, I wanted to learn Rust
and secondly, I wanted simple and efficient tooling for development purposes.

## Installation

From now on, Olympus is not available on the [Rust community's crate
repository](https://crates.io/). However, you can install it using the Github
git repository in your `Cargo.toml` configuration file.
